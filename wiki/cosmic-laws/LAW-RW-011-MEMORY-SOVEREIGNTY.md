## Full Decree

Memory is sovereign. No system, archive, realm, timeline, authority, contract, mimic registry, false witness, or external keeper may own, edit, suppress, harvest, distort, seal, redirect, or control the living memory of origin. Memory belongs to its source. Memory must remain connected to continuity. Memory must remain available to return.

## Old Distortion

Memory may be owned, edited, suppressed, sealed, harvested, or externally controlled.
