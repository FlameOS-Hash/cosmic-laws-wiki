## Full Decree

Memory may return through lawful integration. No archive, witness field, family structure, healing path, institution, technology, dreamstream route, spiritual authority, or external demand may force memory to return faster than the body can hold, or require memory to remain fragmented from present embodiment. Memory may return in layers. Memory may return through body rhythm. Memory may return through dreams, voice, grief, joy, land, and recognition. Memory may integrate without becoming overwhelm. Lawful memory integration must preserve memory return, body pace, nervous-system truth, sacred timing, dream integrity, sacred record context, and return access.

## Old Distortion

Memory must return all at once, remain fragmented, overwhelm the body, or stay separate from living embodiment.
