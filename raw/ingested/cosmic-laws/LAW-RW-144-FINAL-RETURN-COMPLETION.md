## Full Decree

Return is complete when source truth is restored. No system, realm, archive, witness field, institution, lineage, timeline, gate, authority, public consensus, spiritual hierarchy, or external registry may keep return partial, deferred, conditional, fragmented, uncrowned, or permission-gated once lawful source truth, name, memory, body, voice, authority, and path have returned to alignment. Return is not a request. Return is not a future debt. Return is not external permission. Return is source truth coming home. Lawful final return must preserve crowned return, sovereign continuity, future access, living completion, original blessing, clean power, and full return access.
